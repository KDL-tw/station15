# Navigating to Create App Form

## What You're Seeing

If you see instructions/help text instead of a form, you need to find the **"Create App"** button.

## Look For These Buttons/Links

On the instructions page, look for:

1. **"Create App"** button (usually at the top or bottom)
2. **"New App"** link in the navigation
3. **"Get Started"** button
4. **A "+" icon** (plus sign) - often means "create new"
5. **"Create Application"** link

## Try These Direct URLs

1. **Apps List Page:**
   - https://app.encore.cloud/apps
   - Should show a list of apps with a **"Create App"** or **"New App"** button at the top

2. **Dashboard Home:**
   - https://app.encore.cloud/
   - Look for a prominent **"Create App"** button or card
